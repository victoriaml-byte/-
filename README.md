# Что покупает клиент Груши

Интерактивный дашборд на **Vue 3 + d3.js v7** по заказам клиента сервиса доставки продуктов «Груша» (датасет первой недели: 944 доставленных заказа с сентября 2021 по август 2026).

Домашнее задание «Визуализация», неделя 4 · Виктория Мельникова

## Что на дашборде

1. **Месяц к месяцу.** Заказы, сумма трат, средний чек и средняя скидка: значение за последний месяц, изменение к прошлому месяцу и к тому же месяцу год назад, динамика за 24 месяца. Наведение на любой месяц пересчитывает все четыре карточки, клик закрепляет месяц.
2. **Что клиент заказывает чаще всего и на что тратит больше всего.** Топ-15 товаров: слева штуки, справа рубли, в центре фото товара. Сортировка по штукам или по рублям. В тултипе - сколько куплено и потрачено и график цены на полке за всю историю: что клиент заплатил и когда была скидка.
3. **Наблюдения.** Постоянная корзина (товары, которые клиент берёт почти каждый месяц), что подорожало сильнее всего, сколько сэкономлено на скидках.
4. **Категории.** Траты, доля, заказы, штуки, средняя скидка, динамика трат за 24 месяца и три самых частых товара. Клик по строке добавляет категорию в фильтр.

Фильтры сверху: категории (можно выбрать несколько) и период для блока товаров и категорий (12 мес, 24 мес, всё время). Есть тёмная тема по настройке системы.

## Как считаются метрики

- Учтены только доставленные заказы, отменённые показаны отдельно.
- Сумма трат - Σ `amount`, включая доставку и упаковку.
- Средний чек - сумма трат / число заказов.
- Средняя скидка - Σ(`discount` × `quantity`) / Σ(`price` × `quantity`) по товарам без «Услуг Груши».
- При фильтре по категориям заказ учитывается, если в нём есть товар из выбранных категорий, а траты - только по этим товарам.

## Структура

```
index.html        - подключение библиотек и точка монтирования
css/main.css      - токены цветов, светлая и тёмная тема, адаптив
js/app.js         - корневое Vue-приложение: состояние, фильтры, агрегаты, шаблон
js/charts.js      - Vue-компоненты на d3: MonthChart, ItemsButterfly, Sparkline, график цены в тултипе
js/utils.js       - загрузка CSV, метрики, форматтеры (русская локаль), тултип
data/orders.csv   - заказы
data/items.csv    - товар → картинка
img/items/*.jpg   - фото товаров
```

## Запуск

Данные грузятся через `d3.csv`, поэтому нужен веб-сервер: `python -m http.server` в папке проекта → http://localhost:8000. На GitHub Pages: Settings → Pages → Deploy from a branch → `main` / root.
